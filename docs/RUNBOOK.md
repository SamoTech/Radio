الموقع سليم لما تتوفر كل دي:

4. **الواجهة حية**: الصفحة الرئيسية تفتح وعدادات الكتالوج تظهر.

## 4) الطوارئ — العَرَض ← الإجراء

### 🔴 Validate أحمر على PR أو main
1. **القاعدة:** مفيش دمج قبل الفهم — ولا fix يتدفع «عشان نجرب».
2. طبّق **debug-ci** (موثق بالتفصيل في AGENTS.md §5): ci.yml مؤقت على الفرع بصلاحية contents:write يوجه مخرجات كل خطوة لملفات نصية بـ continue-on-error وخطوة تدفعها → اقرأ الملفات من الفرع → **احذفها وأعد ci.yml الأصلي قبل الدمج**.
3. أخطاء شائعة اتعملت قبل كده:
   - «Invalid workflow file ci.yml» → غالبًا اسم خطوة فيه `: ` غير مقتبس (YAML) — اقتبس الاسم.
   - فشل اختبار Python → شغّل نفس الاختبار محليًا: `python -m unittest tests.test_crawler -v` وشوف الرسالة الحقيقية.
   - Lighthouse < 90 → غالبًا contrast أو aria — افحص آخر تغيير CSS/HTML.
4. لو فشل مرتين ومفيش حل واضح: ارجع الفرع وانتقل لبند أصغر (البروتوكول) — المشروع لازم يفضل أخضر.

### 🔴 update-data فاشل أو بيلزق تكرار
1. الفشل المقصود بالتصميم: لو مصدر واحد واقع، الـ run بيعلّم في اللوج وكمّل بطبقات الاحتياط — ده مش خطأ.
2. لو الـ run نفسه أحمر: أغلب السبب واحد من: (أ) سباق خط بيانات (تحديثان متتاليان) — الحل الموجود والمُثبت: rebase بـ `-X theirs` — **لا تُعدَّله** (R-07)؛ (ب) workflow file بايظ — Validate كان هيكشفه.
3. الدليل الأرضي إن الـ run نجح: **data commit جديد** على main — مش لون الصفحة (renders قديمة ساعة كاملة).

### 🔴 تبويب SDR فاضي أو بيانات KiwiSDR قديمة
سلسلة الجلب ثلاثية (PR #117): AetherSDR CDN → `rx.kiwisdr.com/json` → **اللقطة المؤرشفة من المستودع نفسه** (raw + Pages، بطوابع زمنية صادقة — لو شفت `source` فيه «repo archive …» يبقى المصدرين الأصليين واقعين والبيانات مؤرشفة مش طازة).
1. اتفرج على `data/kiwisdr.json` آخر commit — لو `updated` قديمة، شوف اللوج.
2. اتصل يدويًا بطبقة: `curl -s https://cdn.aethersdr.com/kiwi.json | head -c 300` — لو مفيش رد، جرب `http://rx.kiwisdr.com/json/`.
3. حتى لو الثلاثة واقعين: **التبويب شغال من آخر snapshot** — مفيش إجراء حرج.

### 🔴 المحطات مش بتتحدث (كتالوج متجمد)
1. تحقق من آخر `chore(data): refresh stations` — لو أقدم من 24 ساعة شوف لوج الـ run.
2. سقوط Radio-Browser لوحده مش بيجمّد الكتالوج: فيه fallback merge (curated داخل snapshot القديم) + مصادر world (IPRD/verified/Icecast).
3. بعد أي إصلاح: انتظر data commit جديد — هو الدليل.

### 🔴 الموقع كله مش فتح (Pages)
1. اتأكد الأول إن المشكلة مش عندك: جرب `https://samotech.github.io/Radio/data/stations.manifest.json` — لو رد، الاستضافة شغالة والمشكلة كاش متصفح/sw.
2. لو Pages نفسه واقع: راجع آخر deploy في الـ run (آخر خطوة في update-data) — مفيش تدخل يدوي؛ الجري التالي هينشر.
3. **ممنوع نهائيًا:** دفع مباشر لـ main «للإصلاح السريع» (حادثة 2026-10-31) — أي إصلاح من مسار PR حتى وقت الطوارئ.

### 🟡 الزوار على نسخة قديمة (sw مش بيتحدث فورًا)
G-14 معروف: كل sw bump = الزوار على النسخة القديمة حتى أول navigation/refresh. الإفصاح للعميل في رد الشحن: «الزوار محتاجين refresh واحد». مش طوارئ.

### 🔴 عدّادات Abacus باظت أو معدلات ملهاش سقف
R-05 معروف (P2-4 مؤجل): العدادات خشنة وقابلة للتلاعب — مش بتأثر على أي وظيفة أساسية؛ تجاهلها وقت الطوارئ.
