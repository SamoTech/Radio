# دليل استلام Radio Atlas لأي AI أو مطوّر

آخر مراجعة: 2026-11-23. هذا دليل لفهم المشروع قبل التنفيذ؛ قواعد الصلاحيات والدمج في [AGENTS.md](../AGENTS.md)، والأولويات في [ROADMAP.md](../ROADMAP.md). لا تنشر أو تعلن إنجازًا اعتمادًا على هذا الملف وحده.

## 1. فكرة المشروع وتجربة المستخدم

راديو أطلس يجمع نوعين مختلفين: محطات إنترنت ذات بث جاهز (FM tab)، وأجهزة استقبال فعلية قابلة للضبط عن بعد (SDR). المستخدم يبحث ويستمع داخل الموقع ويضبط الجهاز حيث البروتوكول يسمح، مع رابط صريح لواجهته الأصلية عند الحاجة. الهدف تجربة راديو حقيقية: تردد ووضع ومرشح وكسب وإشارة وذاكرة، لا مجرد دليل روابط. الواجهة عربية RTL وإنجليزية LTR، قابلة للتثبيت PWA. لا نفترض أن كل جهاز مدرج يعمل أو أن كل أدواته مدعومة. الواجهة بمظهر راديو خشبي عتيق لامع (سمة Vintage Wood منذ v102): خشب جوز/ماهوجني مصقول ونحاس ذهبي وواجهات أقراص كريمية، بمتغيرات CSS مخصصة وتدرجات متعددة الطبقات؛ لا تغيّر السمة بنية الصفحة أو وظائفها.

واجهة التطبيق وكتالوجه منشوران على GitHub Pages. تحديث البيانات يعمل عبر GitHub Actions وPython، ولا يحتاج جهاز المالك. Cloudflare Kiwi bridge خدمة مستقلة لاتصالات الأجهزة HTTP/WS؛ عبارة «Static بالكامل» تصف استضافة الواجهة فقط ولا تصف جميع مسارات الاستقبال.

## 2. أول قراءة قبل أي تعديل

1. AGENTS.md ثم ROADMAP.md ثم README.md، ثم هذا الدليل و[الحالة الحالية](PROJECT_STATUS.md).
2. `git status --short` و`git log -8 --oneline`، وافحص أحدث main قبل إنشاء الفرع. لا تمس تغييرات شخص آخر.
3. اقرأ الملف المسؤول واختباراته وworkflow المختص. الأقسام التاريخية تشرح ما حدث وقتها، وليست حالة آنية.
4. سجّل نطاق المهمة وبند ROADMAP، نفّذ واختبر ثم افتح PR؛ لا دفع مباشر إلى main.

## 4. مسارات البيانات والصوت

- المحطات: مصادر خارجية وقوائم منسقة → crawler مجدول → JSON/manifest/delta وصفحات SEO → GitHub Pages → كتالوج المتصفح وIndexedDB → مشغّل المحطات. التحميل الأول يبدأ بملف head؛ بقية الكتالوج والتحديث التفاضلي لهما مسار منفصل.
- Kiwi HTTP: زر المستخدم → موصل Kiwi في SDR → WSS للـWorker → فحص Origin وكتالوج `ext_api` والحصص وDNS → WS/SND للجهاز → رسائل MSG والتفاوض ثم PCM → Web Audio → تأكيد غير صفري في الجلسة. Kiwi HTTPS يمكنه الاتصال مباشرة عند إتاحة WSS.
- OpenWebRX: زر المستخدم → WSS مباشر إلى جهاز HTTPS → بروفايل/نطاق وتفاوض PCM → Web Audio، ورسائل FFT فعلية للرسم. لا يمر بهذا الـKiwi Worker.
- بدء SDR يوقف FM، والعودة إلى FM تغلق SDR. تغيير الجهاز أو إغلاقه يجب أن ينظف socket ومؤقتات وAudioContext والرسم، ولا يمس المفضلة.

## 5. مصفوفة الدعم الفعلي

| النظام | داخل مشغّل أطلس | حدود يجب إبقاؤها واضحة |
|---|---|---|
| محطات الإنترنت | بث متوافق وHLS وبدائل وروابط مشاركة ومفضلة وMedia Session | الرابط المرشح وHTTP200 ليسا ضمان تشغيل؛ FM relay غير مفعّل |
| KiwiSDR | SND/PCM وضبط تردد ووضع ومرشح وAGC وكسب وsquelch وإشارة وذاكرة40ترددًا | ext_api وإذن الجهاز والخانات؛ لا ADPCM/IQ؛ لا Kiwi W/F أو decoder كامل |
| OpenWebRX/+ | PCM غير مضغوط + ADPCM (IMA) وبروفايلات ونطاقات وأوضاع تناظرية وإشارة وFFT/waterfall | أجهزة HTTPS/WSS المتوافقة فقط؛ الأنماط الرقمية خارج الموصل الحالي؛ التحقق بالاستماع الحي لـADPCM ما زال مفتوحًا |
| WebSDR | واجهة الجهاز الأصلية عند إتاحة التضمين، أو رابط خارجي | لا موصل native عام مثبت لكل WebSDR |
| SatNOGS | دليل محطات/رصد وروابطها | ليس صوت HF مباشرًا قابلًا للضبط |
| EIBI/WSPR/NOAA | جداول ونشاط انتشار وطقس فضائي | ليست قنوات صوت إضافية |

## 6. حالة التشغيل والأدلة

راجع [PROJECT_STATUS](PROJECT_STATUS.md) أولًا. علامة «نجح في اختبار سابق» مأخوذة من `data/receiver_audio_checks.json` ولا تعني «متصل الآن». علامة «صوت اتأكد في الجلسة دي» تخص جلسة المتصفح بعد العينات غير الصفرية؛ لا تحدد هوية المحطة ولا تشهد بالسماع من سماعة فعلية.

قبرص نجح في إعادة فحص UI بتاريخ2026-11-22 بعد إصلاح v90، والتبديل بين864و819kHz لم يُسقط حالة الاستقبال. السقف الدقيق للحصص وتنظيف leases وDNS TOCTOU والثبات الطويل تظل بنود قبول مفتوحة. لا تستنتج HTTP429 من رسالة تعذر WebSocket وحدها، ولا تنشر Worker لمجرد فشل جهاز واحد.

## 7. التشغيل والاختبارات

للتجربة المحلية استخدم البيانات الموجودة؛ لا تحتاج crawler أو Cloudflare محليًا لتصفح الواجهة:

```bash
python -m http.server 8000
node --check js/app.js
node --test tests/kiwi-native.test.cjs tests/kiwi-worker.test.cjs tests/kiwi-quota.test.cjs
python -m unittest discover -s tests -p 'test_*.py'
```

بوابة المستودع الكاملة: `node --test tests/*.test.cjs` وكل ملفات ES تمر `node --check`، وPython compile/unittest، وWrangler dry-run، وLighthouse وفق `.github/workflows/ci.yml`. مجموعة Node تتضمن اختبارات Worker حي تحتاج شبكة؛ تعذر DNS محلي يُذكر كما هو ولا يُخفى ولا يُعامل كخلل كود مثبت. لا تغيّر الاختبارات لتخطي العطل البيئي.

Playwright وChromium مطلوبان لاختبارات المتصفح؛ اقرأ إعداد workflow الخاص بها. `scripts/kiwi_audio_qa.cjs` افتراضيًا يستخدم تسجيلًا حقيقيًا محفوظًا؛ `KIWI_QA_LIVE=1` يستهلك اتصالات عامة. يمكن حصره بجهاز مدرج عبر `KIWI_QA_RECEIVERS` حسب السكربت. لا تشغّل live من دون داعٍ، لا تختبر حدود الحصص بضغط على الأجهزة العامة، وأغلق كل جلسة. اختبار HTTP الآمن: `node scripts/kiwi_production_smoke.cjs`، لا يحجز SDR.

## 8. النشر وقواعد الإنجاز

- فرع → commit conventional → PR → Validate وGitGuardian خضراء → إعادة قراءة head → squash merge مع SHA كامل40حرفًا. اتبع AGENTS بدل اختراع استثناءات.
- push إلى main في update-data ينشر الكود دون crawler كامل؛ جدول المحطات02:17UTC وجدول SDR كل6ساعات عند الدقيقة11. لا تغيّر جدولة البيانات ضمن تعديل واجهة.
- بصمات `build-info.json` وفاحص production provenance هما دليل الملفات المنشورة؛ نجاح merge أو data commit وحده لا يثبت نسخة الواجهة الحية. راجع [PRODUCTION_VERIFICATION](PRODUCTION_VERIFICATION.md).
- نشر Pages لا ينشر Cloudflare. نشر Kiwi يحتاج مصدره وربط `KIWI_QUOTAS` ومهاجرة SQLite معًا من حساب المالك، وإثبات مستقل بعده. لا تستبدل Worker أحدث اعتمادًا على حزمة قديمة.
- تحديث واجهة يستلزم SW bump ومزامنة README/ROADMAP. التوثيق فقط لا يحتاج bump. لا توجد backticks أو template interpolation داخل `js/app.js`.
- لا أسرار أو IP أو تسجيلات خاصة في الأدلة. استبعاد IL في crawler/client سياسة ثابتة. لا تتجاوز كلمة سر جهاز أو إذن API.

## 9. كيف تواصل الشغل وتسلّمه

اختر أولوية ROADMAP ضمن طلب المالك؛ لا تعلن اكتمال «كل الأجهزة» أو P0 العامة بسبب نجاح عينة. اقرأ الاختبار المقابل، غيّر أقل نطاق مسؤول، وحدث الوثائق في PR نفسه. لا تعِد تنفيذ منجز قديم قبل فحص main. اذكر في التسليم: ما تغير، رابط PR/commit، ما اختُبر وعلى أي نسخة، ما فشل أو لم يُختبر، وهل التغيير منشور أم ينتظر CI. تواصل مع المالك بالمصري.
