➕ اقتراح محطة أو مصدر جديد

بنحب نوسّع الكتالوج دايمًا — سواء محطة محلية، راديو رسمي، أو مصدر جديد كامل (دليل محطات، شبكة SDR، قاعدة بيانات). افتح issue بعنوان واضح مع رابط المصدر وهنراجعه ونضيفه في أقرب تحديث للزاحف.

🐞 مشكلة تقنية أو اقتراح تطوير

المشروع مفتوح المصدر: أي اقتراح واجهة، ميزة جديدة، أو إصلاح عطل — سجّله على صفحة المشاكل والمقترحات، أو ابعت Pull Request مباشرة إذا كنت مطورًا.

⚖️ استفسارات قانونية أو حقوق نشر

لأي شأن يخص حقوق النشر أو المحتوى المرخّص، راجع صفحة حقوق النشر لتفاصيل الإجراء.
